### Elixir and Ruby developer. Building for the web for 20+ years.

I make [Rocket Validator](https://rocketvalidator.com) and write open-source libraries in Elixir and Ruby.

### Projects

- 🚀 **[Rocket Validator](https://rocketvalidator.com)**: site-wide HTML and accessibility checker. Elixir and Phoenix, running since 2016.
- 🕵️ **[MetaInspector](https://github.com/jaimeiniesta/metainspector)**: Ruby gem that pulls the title, meta tags, links and images out of a web page.
- 🧪 **[Funkspector](https://github.com/jaimeiniesta/funkspector)**: the same idea in Elixir, plus XML sitemaps.
- 📊 **[Eurostatx](https://jaimeiniesta.com/en/eurostatx)**: Elixir library for the Eurostat API.
- 🇪🇸 **[Inex](https://jaimeiniesta.com/en/inex)**: Elixir client for the API of INE, Spain's national statistics institute.
- 🔭 **[SpaceTAP](https://github.com/jaimeiniesta/space_tap)**: Elixir client for the IVOA Table Access Protocol, used by astronomical data archives.
- 🏠 **[jaimeiniesta.com](https://jaimeiniesta.com)**: home base, with live demos.
